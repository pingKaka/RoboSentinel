The runtime tracks segmentation masks and robot state over time. Each evidence object directly selects one measurement and one operator:
- entity.visible_any: boolean, entity visible in at least one camera.
- entity.missing_all_cameras: boolean, entity absent in every camera.
- entity.camera.mask_centroid_x/y: mask center in [0,1]; requires entity and camera.
- entity.camera.mask_area_ratio: mask area / image area; requires entity and camera.
- entity.camera.tracking_quality: confidence in [0,1]; requires entity and camera.
- relation.centroid_distance: normalized mask-center distance; requires "entities":["first_id","second_id"] and camera.
- relation.mask_iou: mask intersection / union; requires "entities":["first_id","second_id"] and camera.
- relation.mask_coverage_a: intersection / first entity mask area; requires "entities":["first_id","second_id"] and camera. Prefer this to test whether the first entity is inside the second.
- relation.mask_coverage_b: intersection / second entity mask area; requires "entities":["first_id","second_id"] and camera.
- robot.tcp_x: TCP x position in meters.
- robot.tcp_y: TCP y position in meters.
- robot.tcp_z: TCP z position in meters.
- robot.gripper_position_normalized: number in [0,1]. Opening direction is unknown, so use changed or stable only.

Operators and required parameters:
- eq: value
- gt or lt: value
- between: min, max
- changed: delta, direction (any/increase/decrease), window_sec
- stable: tolerance, window_sec
- all or any: args containing evidence objects
Do not add parameters not listed for the selected operator.
